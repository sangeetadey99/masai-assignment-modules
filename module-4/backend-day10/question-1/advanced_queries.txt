Step 2: Aggregate Queries:-
1.Count the total number of students:-
select count(*) as total_students from students;
output:-
| total_students |
| -------------- |
| 7              |

2.Find the average age of students:-
select avg(age) as average_age from students
output:-
| average_age         |
| ------------------- |
| 24.0000000000000000 |

3.Find the minimum and maximum age:-
select min(age) as min_age, max(age) as max_age from students
output:-
| min_age | max_age |
| ------- | ------- |
| 21      | 27      |

4.Count how many students are enrolled in each course:-
select course, count(*) AS student_count from students group BY course
output:-
| course       | student_count |
| ------------ | ------------- |
| DevOps       | 1             |
| UI/UX        | 1             |
| Backend      | 1             |
| Frontend     | 1             |
| Mern Stack   | 2             |
| Data Science | 1             |

5.Count students whose age is greater than 20
select count(*) as count_above_20 from students where age > 20
output:-
| count_above_20 |
| -------------- |
| 7              |
