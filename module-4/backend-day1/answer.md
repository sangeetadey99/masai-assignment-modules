## Q1. Role of Frontend (FE)
**Explain the role of Frontend (FE) in a web application. Include points related to:**
* User interface
* User interaction
* Communication with backend

**Answer:-** *The Frontend is the part of a web application that users directly see and interact with in the browser. Its main role is to provide a smooth and user-friendly experience.*

**User Interface (UI):-** *Frontend is responsible for designing and displaying buttons, forms, text, images, and layouts so that users can easily understand and use the application.*

**User Interaction:-** *It handles user actions like clicking buttons, filling forms, scrolling pages, and showing instant feedback such as validation messages or loading indicators.*

**Communication with Backend:-** *The frontend sends requests to the backend (for example, to fetch data or submit a form) and displays the response received from the server in a readable format.*

*In short, frontend connects users with the application’s functionality in a visual and interactive way.*

## Q2. Role of Backend (BE)
**Explain the role of Backend (BE) in a web application. Include points related to:**
* Server-side processing
* Database handling
* Security and authentication

**Answer:-** *The Backend is the part of a web application that works behind the scenes and is not directly visible to users. It manages data, logic, and security.*

**Server-side Processing:-** *Backend processes requests coming from the frontend, applies rules or logic, and prepares appropriate responses.*

**Database Handling:-** *It stores, retrieves, updates, and deletes data in databases such as user information, orders, or product details.*

**Security and Authentication:-** *Backend ensures that only authorized users can access protected data by handling login, authentication, and data validation.*

*Overall, the backend ensures that the application works correctly, securely, and efficiently.*

## Q3. Business Logic
**What is Business Logic? Explain in detail and give at least 3 real-world examples where business logic is applied in a web application.**

**Answer:-** *Business Logic refers to the rules and conditions that define how an application behaves based on real-world requirements. It decides what should happen when a user performs an action.*

**Real-world examples:-**

**1. E-commerce Website:-** *Applying discounts only if the cart value is above a certain amount.*

**2. Banking Application:-** *Preventing money transfer if the account balance is insufficient.*

**3. Food Ordering App:-** *Allowing order placement only when the restaurant is open.*

*Business logic is usually implemented on the backend to maintain consistency and security.*

## Q4. Client–Server Model
**What is the Client–Server Model? Explain:**
* Who is the client
* Who is the server
* How communication happens between them

**Answer:-** *The Client–Server Model is a system where two separate components work together to deliver a web application.*

**Client:-** *The client is the user’s device or browser (such as Chrome or Firefox) that sends requests and displays data.*

**Server:-** *The server is a machine or program that receives client requests, processes them, and sends back responses.*

**Communication:-** *Communication happens through HTTP/HTTPS requests. The client sends a request, and the server responds with data or confirmation.*

*This model helps in separating responsibilities and makes applications scalable.*

## Q5. Three-Tier Architecture
**What is 3-Tier Architecture in web applications? Explain each layer:**
1. Presentation Layer
2.  Application (Business) Layer
3.  Data Layer
* Also mention why this architecture is used.

**Answer:-** *Three-Tier Architecture is a design pattern that divides a web application into three separate layers for better organization and maintenance.*

**1. Presentation Layer:-**
*This is the frontend layer where users interact with the application (UI).*

**2. Application (Business) Layer:-**
*This layer contains business logic and handles processing between frontend and database.*

**3. Data Layer:-**
*This layer manages data storage and retrieval using databases.*

**Why it is used:**
* Improves scalability
* Makes maintenance easier
* Enhances security
* Allows independent development of each layer

## Q6. JavaScript as a Backend Language
**Why is JavaScript used as a backend language? Explain with points such as:**
* Performance
* Ecosystem
* Popular backend frameworks

**Answer:-** *JavaScript is used as a backend language because it is fast and flexible.*

**Performance:-** *JavaScript can handle many requests at the same time.*

**Ecosystem:-** *It has many tools and libraries to help developers.*
